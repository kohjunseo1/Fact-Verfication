# Fact-Verfication 연구 계획서
## 근거 기반 Multi-hop 사실 검증

### 왜 필요한가
- LLM은 할루시네이션 문제가 남아 있어, 생성 결과를 외부 근거로 검증하는 단계가 필요하다.
- 실제 주장은 여러 문서를 이어야 확인되는 경우가 많다 → multi-hop 검증 능력이 필요하다.

### 데이터
| | FEVER | HOVER |
|---|---|---|
| 규모 | 145,449개 | 18,171개 |
| 과제 | 대부분 단일 문서 검증 (3분류) | 2~4홉 검증 (2분류) |
| 역할 | 판정 모델 기초 학습 | multi-hop 능력 평가 |

### 데이터 분석에서 찾은 것
1. **근거 없이 맞히는 지름길:** FEVER REFUTES의 28.6%에 부정어가 있다 (SUPPORTS는 1.5%).
2. **홉이 늘수록 어려워지는 구조:** HOVER의 NOT_SUPPORTED 비율은 2홉 28% → 4홉 59%, claim 길이는 평균 18단어 → 32단어로 늘어난다.
3. **정밀한 대조가 필요한 변형 쌍:** 같은 원본에서 단어 1~2개만 바꿔 라벨이 뒤집힌 claim 쌍이 수천 개 있다.
4. **근거 위치의 쏠림:** 근거 문장의 36%(FEVER), 54%(HOVER)가 문서 첫 문장이다.

### 접근 방법
- 파이프라인: 문서 검색 → 근거 문장 선택 → 판정
- multi-hop: 반복 검색, LLM 기반 claim 분해
- 평가: 홉별 macro-F1, claim-only 기준선 대비 개선 폭, 변형 쌍 대조 평가

### 기대 결과
- 지름길이 아닌 근거 기반 판단 능력을 분리해서 측정한다.
- 홉 수에 따라 어디서 성능이 무너지는지(검색인지, 판정인지) 밝힌다.
